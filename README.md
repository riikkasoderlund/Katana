# COO Operating System

This repository is your operational backbone. Everything is markdown. Claude handles the organization.

## How to Use This

Just talk to Claude:
- "Good morning" → Get your daily briefing
- "Prep for 1:1 with Sarah" → Get context and history
- "Process this meeting" → Extract actions and decisions
- "Log a decision about X" → Structured decision capture
- "What's open?" → See all action items

## Structure

```
/daily/          Daily briefings and priorities
/meetings/       Meeting notes and processing
/people/         1:1 context and relationship history
/decisions/      Decision logs with rationale
/actions/        Action items (open + archive)
/templates/      Reusable templates
```

## Files You'll See Often

- `/actions/open-items.md` - Everything that needs doing
- `/daily/YYYY-MM-DD.md` - Today's priorities and log
- `CLAUDE.md` - How Claude operates in this system

## Philosophy

- **Zero friction**: You never think about where things go
- **Context accumulation**: Every interaction builds institutional memory
- **Conversational**: No forms, just natural language
- **Proactive**: Claude surfaces what you need to know

Start by saying "Good morning" to Claude.
